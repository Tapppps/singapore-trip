Optional Alternatives

Use these only if weather, energy and time suit. They are not forced into the main route.

Singapore Flyer

Best around sunset / blue hour for elevated Marina Bay views.

Sentosa

VivoCity → Sensoryscape → Beach Station → Palawan Beach. Better as a half-day alternative.

Flower Dome

Indoor cooled conservatory at Gardens by the Bay. Kept in the main Day 1 plan but easy to skip if short on time.

Singapore River Cruise

Optional loop from Clarke Quay Jetty: Clarke Quay → Boat Quay → Merlion / Marina Bay → Marina Bay Sands / Esplanade → Clarke Quay.

Best fitted into a late-afternoon/evening river day so you get daylight, sunset and night views.
